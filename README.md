# OmniAI 

Create an AI assistant with following features:

image generation

best answers; neither be too long nor be too short

friendly answers like chatgpt

simple, premium appearance, like gemini or grok

website/app builder like grok or ai studio

directly generating website/app

very advanced code writing like claude or deepseek or codex

very advanced mathematics and reasoning

very advanced STEM

efficient for every single task like chatpgt

pdf generation (if asked)

Talking directly by voice (voice chat)

file upload

read the reply aloud

copy the reply

like/dislike the reply

branch the reply to new chat

copy the prompt

edit the prompt

delete the prompt along its reply

new chat

temporary chat

saves chat history

remane, delete, pin the chat

chat search

one single which expands and show following options: think deep, instant reply advanced reasoning and mathemtics, build (for building app or website), generate, web search

voice to text

circle anywhere on the screen to search about it

is adding  generated images and appearance/design in pdf feature available for free

give greeting on the starting page (like Good morning [username] 😊. What's going on?)

know multiple languages

no abusive content

no harm to any person

option which automatically correct grammar, spellings and sentence formation of the prompt

multiple file upload

projects option on sidebar

100% (or sometimes 99.9%) accurate answers

accuracy like gemini, chatgpt, or grok

google/microsoft/apple account/phone no./email login

stay updated like perplexity or gemini

automatically update itself it any updates are there

view visualizations if needed in STEM. (like chatgpt)

ask for: microphone, camera, file access, notification and other essential permissions
